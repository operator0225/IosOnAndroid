# tools

Build scripts, local test-fixture generation helpers, and the automated
test harness. Test fixtures are ARM64 Mach-O binaries built locally by a
developer with their own Apple toolchain — never committed to this repo
(see [../docs/LEGAL.md](../docs/LEGAL.md)).

Status: not started. See [Phase 0](../docs/ROADMAP.md#phase-0--architecture--scaffolding-current)
